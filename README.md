# Afisha Pipeline

Единый конвейер контента для афиши мероприятий ЕКБ ГИД: от анонса в чужом
Telegram-канале до карточки события на сайте.

## Компоненты в этом репозитории

### `repost-bot/`
Telegram-бот на aiogram 3. Принимает пересланные посты (текст, фото,
альбом, видео, документ), переписывает текст через OpenAI по
фиксированному промту, публикует результат в канал **"На выкладку"** с
оригинальными вложениями. Работает через FIFO-очередь в SQLite с
ретраями, переживает рестарт. Подробности и промт — в
`repost-bot/README.md`.

**Деплой:** Supervisor, program name `telegram-repost-bot`, код на VPS в
`/root/repost-bot` (венв и `.env` не в репозитории — создаются на месте).

### `afisha-bot/`
Telegram-бот, принимающий уже переписанные анонсы (после ручной правки)
и публикующий их напрямую в Supabase — тот же бэкенд, на котором стоит
`afisha-site`. Также включает видео-прокси (принимает видео от
организаторов, отдаёт по короткой ссылке `video.ekb-guide.ru/v/<token>`,
автоудаление по TTL).

**Деплой:** Supervisor (`afisha-bot`, `afisha-video-proxy`), конфиги в
`afisha-bot/deploy/`.

### `afisha-site/`
Фронтенд афиши: встраиваемый виджет (`index.html`, `embed.js`), админка
(`admin.html`), SSR SEO-страницы отдельных событий (`event.php`),
конфиг подключения к Supabase (`sb-config.php`). Работает на **Timeweb**
(домен `afisha.ekb-guide.ru`), не на VPS — компоненты `repost-bot` и
`afisha-bot` физически на другом сервере (VPS `magic-copper`,
`77.110.125.73`). Запросы к Supabase идут через reverse-proxy
`sb.ekb-guide.ru` на VPS, так как из России прямые запросы к `supabase.co`
не проходят без VPN.

## Важно при работе с репозиторием

- Три компонента живут на **двух разных серверах** (VPS и Timeweb) — при
  деплое `afisha-site` файлы вручную/скриптом переносятся на Timeweb,
  автоматического CI/CD пока нет.
- `.env` и любые секреты — только на серверах, в репозитории только
  `.env.example`.
- `repost-bot` и `afisha-bot` — независимые процессы под Supervisor на
  VPS, каждый в своей папке `/root/<имя>`, со своим venv.
